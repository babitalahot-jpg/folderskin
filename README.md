## 🎯 Tips for Best Results

- **Use square images** – For the best-looking icons, try to use images that are square (same width and height). This helps the icon look sharp and properly sized.
- **Keep it simple** – Icons with clear shapes and colors look better when scaled down. Avoid overly busy photos.
- **Organize by color** – Many people use folderskin to color-code their folders. For example, red for urgent work, blue for personal, green for completed projects.
- **Back up your originals** – If you're worried about losing the original icon, folderskin lets you save a backup before making changes.

## 🔧 Troubleshooting Common Issues

Even though folderskin is designed to be user-friendly, you might run into a hiccup. Here are quick fixes:

- **Icon doesn't change** – Make sure you've selected the correct folder. Also, try refreshing your desktop (right-click and select "Refresh" on Windows, or press F5).
- **Download won't start** – Check your internet connection and try again. Some browsers may block downloads—look for a notification and allow it.
- **App won't open** – On Windows, you might see a SmartScreen warning. Click "More info" and then "Run anyway." This is normal for open-source apps.
- **Can't find the downloaded file** – Check your "Downloads" folder. It's usually in your user folder (e.g., C:\Users\YourName\Downloads).
